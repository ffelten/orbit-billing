### 1. `src/orbit/models/` — pattern: Pydantic v2 `BaseModel`, no ORM

Files: `__init__.py` (empty), `plan.py`, `subscription.py`.

- Money column convention — `plan.py`:
```python
class Plan(BaseModel):
    """A named price point.
    Amounts are integer cents per ADR-0002; floats never touch money.
    """
    id: int
    name: str
    amount_cents: int = Field(ge=0)
    interval: PlanInterval
```
- Timestamp/period convention — `subscription.py` uses `datetime`, a `StrEnum` for status, and a `model_validator(mode="after")` for cross-field invariants:
```python
class Subscription(BaseModel):
    id: int
    customer_id: int
    plan_id: int
    status: SubscriptionStatus = SubscriptionStatus.ACTIVE
    current_period_start: datetime
    current_period_end: datetime

    @model_validator(mode="after")
    def _check_period(self) -&gt; "Subscription":
        if self.current_period_end &lt;= self.current_period_start:
            raise ValueError("current_period_end must be after current_period_start")
        return self
```
No existing model has an `expires_at` field yet — ADR-0005 (below) implies one is expected on gift cards.

No SQLAlchemy anywhere — persistence is 100% raw `asyncpg` SQL (see `db.py`, `idempotency.py`, etc.), and Pydantic models are pure in-memory domain objects built from `asyncpg.Record` rows manually (`_charge_from_row` pattern in `billing/idempotency.py`).
